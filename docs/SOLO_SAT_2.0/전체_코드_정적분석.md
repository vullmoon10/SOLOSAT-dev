# SOLO SAT 2.0 전체 코드 정적 분석

## 분석 기준

- 대상: `SOLO_SAT_FINAL_PLZ_2.0`의 프로젝트 Python 소스 29개 파일
- 제외: `.venv` 라이브러리와 실행 중 생성되는 `runtime/local` 데이터 파일
- 각 항목은 실제 소스의 이름·표현식·문서 문자열을 기준으로 기능을 짧게 정리했다.
- 조건문·반복문·예외 처리는 해당 조건식 또는 처리 대상을 함께 기록했다.
- 정적 분석 문서이므로 실행 중 값의 변화나 동작 결과까지 검증한 것은 아니다.
- 소스 코드 자체는 수정하지 않았다. 이 문서는 코드 항목을 설명하는 별도 문서다.

## 참고

- 변수 설명은 선언·대입 위치의 이름과 우변 표현식을 기준으로 작성했다. 동일 변수가 여러 위치에서 재할당되면 각 대입 위치가 별도 항목으로 나타날 수 있다.
- 제어 흐름은 AST에서 확인한 조건식·반복 대상·예외 유형을 간략히 설명한다. 각 분기 내부의 모든 문장을 자연어로 재서술하는 문서는 아니다.
- `__init__` 등 특수 메서드와 이벤트 처리 메서드도 일반 메서드와 동일한 기준으로 정리했다.
