## 1. 프로젝트 개요 및 개발 동기
SOLO SAT는 ‘나 혼자만 1등급’을 부제로 기획한 수학 학습·게임 프로젝트이다. 수학 문제를 풀고 보상을 얻는 학습 과정을 게임의 진행과 연결하여, 학습자가 반복적으로 문제에 도전할 수 있는 환경을 만드는 것을 목표로 하였다.

초기에는 여러 교과목과 다양한 성장 시스템을 포함하는 게임을 구상했으나, 핵심 기능을 먼저 구현하고 검증하기 위해 Python과 Pygame-CE를 활용한 2D 횡스크롤 게임으로 개발 범위를 조정하였다. 본 보고서는 실제 실행을 확인한 SOLO SAT 2.0을 기준으로 작성하였다.

## 2. 프로젝트 목표
핵심 목표는 횡스크롤 게임 진행 중 수학 문제를 제시하고, 정답 여부를 전투와 점수 획득에 연결하는 것이다.

주요 목표 기능은 다음과 같다.
- 닉네임과 월드 시드를 입력하여 새 게임 시작
- 시드 기반 월드 생성
- 난이도별 수학 객관식 문항 생성
- 문제를 제시하는 몬스터와의 상호작용
- 플레이어 이동 및 점프, 이동 발판, 일반 몬스터와 투사체
- 아이템, 점수, 체력, 도전과제 시스템
- 로컬 자동 저장 및 랭킹 기능

## 3. 프로젝트 구현 시 고려사항
Python과 Pygame-CE를 활용하였으며, Python 3.10 이상의 실행 환경을 기준으로 개발하였다.

게임 화면은 메뉴, 닉네임 입력, 시드 입력, 게임 플레이, 문제 풀이 화면 등으로 구분하였다. 키보드와 마우스를 함께 활용할 수 있도록 입력 방식을 구성하였다.

또한 플레이어와 지형·발판·몬스터 사이의 충돌 처리, 문제 생성의 난이도 조절, 월드 생성의 재현성, 저장 데이터의 유효성 등을 고려하였다.

게임 기록은 별도의 서버가 아닌 로컬 JSON 파일에 저장하도록 구성하였다. 같은 숫자 시드를 입력하면 같은 월드가 생성되지만, 이동 속도·중력·점프력은 새 게임마다 별도로 무작위 설정된다.

## 4. 프로젝트 진행 과정
프로젝트는 게임의 기본 콘셉트와 학습·보상 구조를 구상하는 단계에서 시작하였다. 이후 실제 게임의 동작을 확인하기 위해 Python과 Pygame을 이용한 구현을 진행하였다.

기능이 하나의 파일에 집중되지 않도록 `core`, `entities`, `systems`, `ui`, `world` 등의 모듈로 코드를 분리하였다. 이후 플레이어와 몬스터, 월드 생성, 수학 문제 생성, 메뉴 및 HUD, 로컬 저장 기능을 연결하였다.

마지막으로 베타테스트를 통해 게임 진행과 문제 난이도의 균형을 점검하고, 문제 출제 범위를 조정하였다.

## 5. 프로젝트 상세 내용 및 구현 결과
**사용 언어 및 도구:** Python, Pygame-CE

주요 코드 구조는 다음과 같다.
- `main.py`: 프로그램 진입점 및 메뉴와 게임 실행 흐름 관리
- `core/game.py`: 게임 상태, 이벤트, 업데이트 및 렌더링 관리
- `entities/`: 플레이어, 몬스터, 투사체, 이동 발판 구현
- `world/`: 시드 기반 월드와 지형 생성
- `systems/`: 수학 문항 생성, 퀴즈, 전투, 저장, 도전과제 및 오디오 기능
- `ui/`: 메뉴, 입력 화면, HUD 및 게임 화면 렌더링

수학 문항은 초등학교 후반부터 중학교 1학년 수준을 중심으로 구성하였다. 난이도는 쉬움·보통·도전·최상의 4단계로 나누었으며, 난이도에 따라 문제의 계산 과정과 복잡도를 조절한다.

문제 몬스터는 각각 수학 문제를 제시하며, 정답을 맞히면 처치할 수 있다. 이외에도 코인·체력 회복·속도 강화·점프 강화 아이템, 일반 몬스터, 이동 발판, 도전과제 및 로컬 랭킹 기능을 구현하였다.

## 6. 결과물 및 활동 증빙
주요 결과물은 SOLO SAT 2.0의 Python 소스 코드와 실행 가능한 Pygame 프로토타입이다.

보고서에는 다음 화면을 캡처하여 첨부할 수 있다.
1. 메인 메뉴 및 새 게임 화면
2. 닉네임과 월드 시드 입력 화면
3. 플레이어와 몬스터가 등장하는 실제 게임 화면
4. 수학 문제와 선택지가 표시되는 화면
5. 아이템 및 HUD, 도전과제 화면

실제 실행 화면과 GitHub 저장소 링크는 제출 전에 추가한다.

## 7. 문제점 및 해결 과정
프로젝트를 진행하면서 어려웠던 점은 초반에 Pygame에서 플레이어의 움직임을 구현하는 부분과 수학 문제의 출제 범위를 선정하는 것이었다.

특히 플레이어의 이동과 점프 등 기본적인 움직임을 구현하고, 이를 게임 화면 안에서 자연스럽게 작동하도록 만드는 과정에서 어려움이 있었다.

수학 문제의 출제 범위는 개발 초기에는 고등학교 1학년 3월 전국연합학력평가의 2점 문항을 활용하려고 하였다. 그러나 베타테스트를 진행하면서 해당 문항을 게임에 적용했을 때 난이도와 게임 진행의 균형을 조절하기 쉽지 않다는 점을 확인하였다.

이에 따라 문제 출제 범위를 초등학교 후반부터 중학교 1학년 수준으로 축소하였다. 이를 통해 게임의 진행 속도와 문제 풀이 난이도 사이의 균형을 맞추고자 하였다.

## 8. 프로젝트 결과 및 목표 달성도
수학 문제 풀이와 횡스크롤 게임 진행을 연결한 실행 가능한 프로토타입을 구현하였다. 난이도별 문항 생성, 문제 몬스터, 플레이어 이동과 점프, 월드 생성, 아이템, 점수, 도전과제 및 로컬 저장 등 기본적인 게임 시스템을 구성하였다.

다만 초기 기획에 포함된 여러 교과목의 통합과 일부 성장 시스템은 현재 2.0에 모두 구현된 것은 아니다. 따라서 전체 기획을 완성한 단계라기보다는 수학 중심의 핵심 기능을 실행 가능한 형태로 구현하고 검증한 단계로 평가할 수 있다.

## 9. 느낀 점 및 개선 방향
이번 프로젝트를 통해 게임 개발은 캐릭터의 움직임뿐 아니라 충돌 판정, 상태 관리, 문제 생성, 데이터 저장, UI와 사운드 등 다양한 요소가 함께 작동해야 한다는 점을 알게 되었다.

또한 게임에 학습 요소를 결합할 때는 문제의 난이도뿐 아니라 게임의 진행 속도와 보상 구조까지 함께 고려해야 한다는 점을 베타테스트를 통해 확인하였다.

향후에는 플레이 테스트를 통해 이동과 충돌, 저장 및 불러오기 기능을 더욱 안정화하고, 문제 생성의 정확성과 난이도 균형을 개선할 계획이다. 이후 초기 기획에 포함된 다른 교과목과 성장 시스템도 단계적으로 검토하고자 한다.
